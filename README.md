# 🐧 Linux Module 1 – System Administration Practical Guide

Welcome to my Linux Module 1 practical repository! 🚀

This repository covers essential Linux administration concepts and hands-on practicals designed for Linux beginners, system administrators, cloud engineers, and DevOps learners. It includes user and group management, file operations, permissions, package management, SSH connectivity, process and service management, archiving, and file transfer between Linux machines.

## 📚 Topics Covered

### 1. User and Group Management
- Create, modify, and delete users.
- Create and manage groups.
- Add users to groups.
- Configure passwords and account settings.
- Understand `/etc/passwd`, `/etc/shadow`, and `/etc/group`.

### 2. File and Directory Management
- Create, copy, move, rename, and delete files.
- Create and manage directories.
- List files and navigate the filesystem.
- Search for files and directories.
- Understand absolute and relative paths.

### 3. Linux Permission Management
- Understand read, write, and execute permissions.
- Configure permissions using `chmod`.
- Change ownership using `chown` and `chgrp`.
- Understand symbolic and numeric permissions.
- Learn SUID, SGID, and sticky bit basics.

### 4. Linux Booting Process
- Understand the Linux boot sequence.
- Learn about BIOS/UEFI and GRUB.
- Understand the Linux kernel and initramfs.
- Learn about systemd and system targets.
- Troubleshoot basic boot issues.

### 5. Linux Root Directory Structure
- Understand the Linux filesystem hierarchy.
- Explore `/`, `/root`, `/home`, `/etc`, `/var`, `/tmp`, `/usr`, and `/opt`.
- Learn the purpose of `/boot`, `/dev`, `/proc`, `/sys`, and `/run`.
- Understand where configuration files, logs, and user data are stored.

### 6. Package Management – YUM, DNF, and RPM
- Install and remove packages.
- Update installed software.
- Search for available packages.
- Query installed RPM packages.
- Understand package dependencies.
- Learn the differences between YUM, DNF, and RPM.

### 7. SSH – Secure Shell
- Understand remote Linux access.
- Connect to remote servers using SSH.
- Configure SSH keys.
- Copy files securely using SCP.
- Troubleshoot common SSH connection issues.
- Understand basic SSH security practices.

### 8. Archive, ZIP, and Unzip Operations
- Create and extract TAR archives.
- Compress and extract GZIP files.
- Create ZIP archives.
- Extract ZIP files using `unzip`.
- List archive contents.
- Manage compressed backups.

### 9. Linux Help Commands
- Use `man` pages.
- Use `info` documentation.
- Understand the `--help` option.
- Use `whatis` and `apropos`.
- Find command locations using `which` and `whereis`.

### 10. Process Management
- View running processes.
- Understand process IDs (PID).
- Use `ps`, `top`, and `pgrep`.
- Stop processes using `kill` and `pkill`.
- Understand foreground and background processes.
- Learn process priorities using `nice` and `renice`.

### 11. Service Management
- Understand systemd services.
- Check service status.
- Start and stop services.
- Enable and disable services at boot.
- Restart services and inspect logs.
- Practice with `systemctl` and `journalctl`.

### 12. File Transfer Between Linux Machines
- Transfer files using SCP.
- Synchronize files using rsync.
- Connect to remote systems using SSH.
- Copy files and directories between servers.
- Understand remote hostnames, IP addresses, and authentication.
- Troubleshoot file transfer permissions and connectivity.

## 🎯 Learning Objectives

After completing this module, learners should be able to:

- Perform basic Linux system administration.
- Manage users, groups, files, and permissions.
- Understand Linux booting and filesystem structure.
- Install and manage software packages.
- Connect to remote Linux machines securely.
- Archive, compress, and extract files.
- Monitor processes and manage system services.
- Transfer files between Linux servers.

## 💻 Lab Environment

Recommended practice environments:

- CentOS Stream or compatible RHEL-based Linux
- Red Hat Enterprise Linux (RHEL)
- Ubuntu or Debian
- VMware or VirtualBox virtual machines
- Two Linux machines or virtual machines for SSH and file transfer practicals

**Note:** Package management commands differ by distribution. YUM and DNF are commonly associated with RHEL-based systems, while APT is used on Debian-based systems.
